# Изоляция и разбиение тестов — дизайн

Дата: 2026-11-25. Статус: утверждён пользователем (пункт 4 анализа проекта).

## Зачем

`LakeFishingTest.cpp` — 4613 строк и 42 теста в одном файле. Часть тестов исторически «плавает» в общем прогоне (`Food`, `Interactions`, `BanksAndDepth`): `SpawnFish` по умолчанию получает `Seed = -1`, и `ALakeFish::Setup` выводит случайные задатки из `GetUniqueID()` — то есть из того, сколько объектов создали предыдущие тесты. Кроме того, документированная команда `RunTests QuietLake.Fishing` запускает 35 тестов из 49: 12 `QuietLake.Ecosystem.*` и 2 `QuietLake.Prototype.*` в неё не попадают.

## Цели

- Каждая рыба в тесте получает детерминированный seed, не зависящий от порядка тестов и аллокатора.
- Файл разбит по темам; общие фикстуры — в одном заголовке.
- Одна команда запускает все тесты проекта; README/CLAUDE называют верные числа.
- Проверка: сборка и два полных прогона по 49/49.

## Не-цели

- Не менять поведение тестов и проверяемые числа; только изоляция и структура.
- Не трогать игровой код (кроме тестового общего заголовка).
- Не коммитить без просьбы.

## Ограничения

- Тесты создают по нескольку миров внутри одной функции; часть вызывает `GEngine->DestroyWorldContext` явно — обёртку RAII поверх этого не вводим (риск двойного удаления), изоляцию даёт детерминизм seed.
- В файле два блока `#if WITH_DEV_AUTOMATION_TESTS`; после разбиения каждый файл оборачивается одним.
- Комментарии-описания перед тестами переезжают вместе с тестом.

## Подходы

1. **Детерминизм + сплит (выбран).** Seed из параметров рыбы; общий `LakeTestCommon.h`; четыре файла по темам.
2. **Только детерминизм.** Дешевле, но 4600 строк остаются в одном файле.
3. **Обёртка RAII мира + сплит.** Дала бы гарантированное удаление, но при явных `DestroyWorldContext` в 15 местах риск двойного удаления выше пользы; отложено.

## Решение

- `Source/QuietLake/LakeTestCommon.h`: все include, `FLakeFishingFixture`, `inline SpawnFish` с детерминированным seed из вида, веса, координаты и школы (не из `GetUniqueID`).
- Файлы: `LakeFishingTest.cpp` (ловля/удилище/снасти — 13), `LakeFishTest.cpp` (поведение/корм/обучение/стаи/берег — 11), `LakeWorldTest.cpp` (погода/вода/волны/рябь — 6), `LakeEcosystemTest.cpp` (12 прототипов).
- Команда в документации: `Automation RunTests QuietLake` (49 тестов); числа и состав файлов в README/CLAUDE.
- Проверка: `Tools/Build.ps1`, два прогона по 49/49, отдельно `Food`, `Interactions`, `BanksAndDepth`.

## Что оставлено исполнителю

- Точный перенос строк и комментариев скриптом, порядок тестов внутри файлов.
- Формулировки README/CLAUDE.

## Проверка

- `git diff` не меняет игровой код; только тестовые файлы и документы.
- Два полных прогона зелёные; в логах 49 `Test Completed`.
