# Реструктуризация документации QuietLake — дизайн

Дата: 2026-11-25. Статус: утверждён пользователем (пункт 6 анализа проекта).

## Зачем

README разросся до 127 разделов «Проверено …» и перестал быть руководством: новый человек (и агент) не может за минуту понять, как запустить проект, где искать механики и что проверено в последний раз. CLAUDE.md устарел (заявляет 31 тест, фактически 48; не знает про `Tools/FishTraining` и обученные политики). WORLD.md — лучший источник истины по миру, но не связан с остальными документами и не описывает новую экосистему рыб.

## Цели

- README — короткое руководство (100–150 строк): что это, запуск, управление, сборка, краткий обзор со ссылками, последние проверки.
- Полная история проверок сохраняется дословно в `docs/CHECKS.md` с оглавлением.
- WORLD.md — единственный источник истины по миру и механикам; добавляется раздел про обученные политики экосистемы.
- CLAUDE.md — только операции: команды, пути, актуальные списки, карта документации.
- `Tools/FishTraining/README.md` — как обучать и экспортировать веса.

## Не-цели

- Не переписывать историю проверок и не сокращать измерения.
- Не менять код, ассеты, конфиги и карту.
- Не коммитить без отдельной просьбы.

## Ограничения

- Перенос «Проверено» — только скриптом/точной вставкой, без ручного пересказа: риск потери измерений.
- Внутренние ссылки и якоря после переноса должны оставаться рабочими.
- Стиль и язык (русский, комментарии в коде — английский) не меняются.

## Подходы

1. **Перенос истории в архив (выбран).** README → руководство, `docs/CHECKS.md` → полный журнал, README держит последние 3 проверки и ссылку. Плюс: README снова читается; минус: один раз большой диф (~250 КБ) и нужно проверить полноту переноса.
2. **Оставить историю в README, добавить оглавление.** Дешевле, но README остаётся 290 КБ; не решает исходную проблему.

## Что решено (по утверждённому плану)

- `docs/CHECKS.md`: все 127 разделов «Проверено» дословно, плюс оглавление по месяцам; первый абзац — назначение файла и правило пополнения (новые проверки сначала сюда, в README — только последние три).
- `README.md`: вводный абзац, «Что это», «Запуск», «Управление» (кратко), «Сборка и проверки», «Что реализовано» (5–7 пунктов со ссылками в WORLD), «Последние проверки» (3), «Документация» (карта), «План разработки» (сохранить).
- `WORLD.md`: новый раздел «Экосистема рыб: обученные политики» (4 вида прототипа, 13 наборов весов, генерация весов, статус проверки, ограничения), ссылки на `docs/FishEcosystem_Architecture.md` и `Tools/FishTraining/README.md`; из README переносится только уникальное, дубли не дублируются.
- `CLAUDE.md`: 48 тестов в четырёх файлах; `Tools/FishTraining`; карта документации; ссылка на `docs/CHECKS.md`.
- `Tools/FishTraining/README.md`: назначение, скрипты, что генерируют, как запускать, где веса.

## Что оставлено исполнителю

- Точная группировка оглавления CHECKS (по месяцам, с темами) и формулировки разделов README.
- Формат карты документации в README/CLAUDE.
- Проверка полноты переноса и битых ссылок.

## Проверка

- Суммарный объём перенесённых разделов совпадает с исходным (сверка по числу строк/байт блоков).
- `git diff` не содержит изменений в `Content/`, `Source/`, `Tools/*.py` и конфигах.
- В README нет «Проверено» старше последних трёх; в CHECKS — все 127.
- Ссылки между README, WORLD, CLAUDE, CHECKS и FishTraining открываются.
